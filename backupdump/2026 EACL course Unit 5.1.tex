\section{Lexicon \& Grammar}

\begin{frame}[fragile]{HK Hakka lexicon \& grammar}

{\footnotesize
Hakka and Yue share a lot of lexicon.\\
Some typical Hakka lexicon, e.g.:\\
圳 \enquote{field furrow} e.g. 深圳 cím zùn\\
埔 \enquote{little plain} e.g. 大埔 tài pù\\
畲/輋 \enquote{slash \& burn (field)} e.g. 禾輋 vō ciā\\ 
\bigskip
Many nouns with non-gendered semantics carry sex-specific suffixes\\
虱嫲 sĭt mā \enquote*{louse}, 舌嫲 sèt mā \enquote*{tongue}, 薑嫲 gióng mā \enquote*{fresh ginger}\\
蝠婆 pìt pō \enquote*{bat}, 襖婆 ău pō \enquote*{cotton-padded jacket}\\
蝦公 hā gúng \enquote*{shrimp/prawn}, 貓公 miàu gúng \enquote*{cat}\\
鼻公 pì gúng \enquote*{nose}, 腳趾公 giŏk zĭ gúng \enquote*{big toe}\\
猴哥 hēu gó \enquote*{monkey}, 罌哥 áng gó \enquote*{bottle}\\
\medskip
Cantonese has far fewer of these, e.g.:\\
蝨乸 sat1 naa2 \enquote*{louse}, 蛤乸 gaap3 naa2 \enquote*{frog}\\
腳趾公 goek3 zi2 gung1 \enquote*{big toe}\\
鷯哥 liu4*1 go1 \enquote*{hill myna}, 鼻哥 bei6 go1 \enquote*{nose}\\ 
膝頭哥 sat1 tau4 go1 \enquote*{knee}
}
\end{frame}

\begin{frame}[fragile]{HK Hakka lexicon \& grammar}

{\small
\enquote{To be}:\\ 
Hakka universally uses 係 (港客 hè)\\ 
Yue uses 係 (Canto. hai6), but transitions to using 是 is eastern Guangxi (e.g. 玉林粵 ɕi˨˧, 南寧平 ɬi˨)\\
\bigskip
\enquote{To eat}:\\ 
Hakka (at least Neo-Hakka and Shē) universally uses 食 (港客 sìt)\\
Yue: Cantonese uses 食 (sik6), but beyond Cantonese, 吃／喫 is more common, e.g. 港圍頭 \ 吃 hɛk˧˥\textsuperscript{D1}, 中山石岐 \ 喫 jak˧, 南寧平 \ 吃 hɐt˧\\
(Canto. also has 喫 jaak3, but now considered very informal in HK.)\\

\bigskip
\enquote{What}:\\
Hakka: 乜介 mǎk gài, 嘪 mǎi\\
Canto.: 乜 mat1, 乜嘢 mat1 je5, 咩 me1, 咩嘢 me1 je5\\
\quad (嘢 je5: \enquote*{thing})\\
南寧平: 那門 na˧ mun˩
}
\end{frame}
